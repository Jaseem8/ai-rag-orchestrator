# Autonomous Agent Reasoning Model

## The ReAct Protocol
The agent runs an iterative loop:
1. **Thought**: LLM evaluates current state and determines sub-goal.
2. **Action**: LLM triggers a registered tool with JSON arguments.
3. **Observation**: Result from tool execution is injected back into conversation history.
4. **Final Answer**: Emitted once target condition is met.
